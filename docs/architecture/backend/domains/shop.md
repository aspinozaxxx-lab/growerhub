# Домен shop

## Назначение

Хранит предложения готовых комплектов, гостевые заказы и запросы помощи,
снимки состава и цены, обработку администратором и устойчивую очередь уведомлений.
Не управляет оборудованием и не принимает оплату.

## Публичный Facade

`ShopFacade`: `catalog`, `submit`, `list`, `get`, `update`, `retry`,
`claimNotifications`, `finishNotification`.

## Публичные контракты

- `ShopData`: каталог, позиции, контакты, ПВЗ, запрос, квитанция, административная
  карточка и страница. Статусы: `NEW`, `PROCESSING`, `CONFIRMED`, `CLOSED`.
- `ShopException`: стабильный код ошибки, безопасный текст и срок повтора.
- `notification.contract.TelegramData`: резервирование и результат доставки.

## Владение данными

`shop_requests` хранит заказ, снимок состава, контакты, согласие, ПВЗ, UUID и хеш
содержимого; HMAC адреса и телефона ограничивают частоту. `shop_submission_guard`
сериализует короткую транзакцию создания. `shop_notifications` хранит состояние,
попытки, адрес и lease уведомления. Версия и цены определяются серверным
`resources/shop/catalog.json`; frontend использует производный снимок. Модели и
фотографии оборудования остаются в существующем публичном каталоге.

## Используемые домены

- `notification` — только публичные типы технической доставки `TelegramData`.

## Внешние пользователи домена

- REST-адаптер `api.ShopController`.
- Отдельный scheduler `messaging.ShopTelegramWorker`.

## Алгоритм работы

Нормализация → блокировка guard → проверка UUID → доступность и версия → лимиты →
серверный расчёт → атомарная запись заявки и уведомления. Тот же UUID возвращает
неизменную квитанцию, иное содержимое даёт 409. Фильтруемый административный список
и статусы доступны только admin. Worker резервирует пакет, выполняет HTTP вне
транзакции, затем фиксирует результат по lease. Повтор допускается автоматически
только после явного 429; timeout/5xx/истёкший lease становятся uncertain.
Администратор может явно повторить failed, blocked или uncertain. Сообщение
содержит номер и ссылку, без клиентских контактов.

## Ограничения

Без СДЭК API, карты, онлайн-оплаты, верификации ПВЗ, расчёта доставки и наличия.
Покупатель вручную вводит город, номер и адрес ПВЗ. Нет публичного чтения заявки,
MQTT, изменения ферм или регистраций. При выключенном приёме сохраняется безопасный
повтор существующего UUID. Mini — пилот до физической проверки. Настройки и секреты
берутся из окружения; персональные данные не входят в журналы и аналитику.
