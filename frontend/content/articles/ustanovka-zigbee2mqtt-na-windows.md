Zigbee2MQTT можно запустить на обычном постоянно включённом компьютере с Windows. Для первого стенда достаточно USB-координатора с coordinator firmware и одного Zigbee-датчика. GrowerHub выдаёт отдельное защищённое MQTT-подключение, поэтому для новой установки локальный MQTT-брокер не обязателен.

Самый короткий путь — скачать пакет GrowerHub и два личных файла конфигурации из кабинета. Ниже также указано, где искать причину, если Windows не видит USB-стик или Zigbee2MQTT не выходит в сеть.

**Хотите сначала увидеть кабинет?** [Откройте демоферму без регистрации](/app/demo/?lang=ru). В ней уже есть датчики, теплицы и история; USB-координатор для демо не нужен. Ниже — путь для вашего физического оборудования.

## Что понадобится

| Компонент | Минимальный вариант | Что проверить |
|---|---|---|
| компьютер | Windows 10/11, который не уходит в сон во время работы | стабильный интернет и свободный USB-порт |
| координатор | USB-стик Zigbee2MQTT с типом адаптера `zstack` или `ember` | coordinator firmware и тип адаптера |
| программная среда | актуальная LTS-версия Node.js с Corepack | команды `node --version` и `corepack --version` выполняются |
| первое устройство | Zigbee-датчик температуры/влажности | точная модель есть в каталоге совместимости |
| GrowerHub | бесплатная учётная запись | создано подключение и сохранены оба файла конфигурации |

Официальная инструкция Zigbee2MQTT для Windows сейчас указывает Node.js 22 LTS. Перед установкой сверяйтесь с [актуальной страницей Windows](https://www.zigbee2mqtt.io/guide/installation/05_windows.html), потому что требуемая LTS-версия со временем меняется.

## Шаг 1. Определите тип координатора

Windows-пакет GrowerHub и его мастер настройки поддерживают два типа адаптера. Тип выбирают по чипу и прошивке, а не по форме корпуса:

- `zstack` — SONOFF ZBDongle-P и совместимые координаторы на CC2652/CC1352;
- `ember` — SONOFF ZBDongle-E и совместимые координаторы Silicon Labs.

Если в [официальном списке адаптеров](https://www.zigbee2mqtt.io/guide/adapters/) для вашей модели указан другой тип, используйте [официальную инструкцию установки Zigbee2MQTT на Windows](https://www.zigbee2mqtt.io/guide/installation/05_windows.html). Описанный здесь мастер Windows-пакета GrowerHub другие типы не поддерживает.

Дешёвый CC2652P-стик подходит, если в нём установлена именно прошивка координатора. USB-удлинитель помогает вынести радио от корпуса компьютера, USB 3.0 и других источников помех.

## Шаг 2. Создайте подключение GrowerHub

1. Войдите в GrowerHub и откройте мастер первого подключения.
2. Выберите «Новая установка».
3. Введите понятное название и нажмите «Создать подключение».
4. Выберите Windows и сразу скачайте `configuration.yaml` и `secret.yaml`: MQTT-пароль показывается один раз.
5. Откройте пакеты установки и скачайте последний Windows ZIP из [GitHub Releases](https://github.com/aspinozaxxx-lab/growerhub/releases).

В ZIP нет личных данных доступа. Не публикуйте скачанный `secret.yaml` и не отправляйте его в чат; при потере файла выпустите новые credentials в кабинете.

## Шаг 3. Найдите COM-порт

Подключите USB-стик и откройте «Диспетчер устройств → Порты (COM и LPT)». Запомните номер рядом с USB Serial Device, например `COM4`.

Если раздела с портом нет:

1. переставьте стик в другой USB-порт;
2. проверьте его на другом компьютере;
3. установите VCP-драйвер производителя USB-UART чипа — Silicon Labs, FTDI или WCH;
4. убедитесь, что кабель или удлинитель передаёт данные, а не только питание.

Эти же причины перечислены в [документации поддерживаемых адаптеров](https://www.zigbee2mqtt.io/guide/adapters/).

## Шаг 4. Подготовьте пакет

1. Распакуйте ZIP в постоянную папку, например `C:\GrowerHub\zigbee-coordinator`.
2. Поместите `configuration.yaml` и `secret.yaml` в подпапку `data`.
3. Запустите `setup-coordinator.bat`.
4. Выберите найденный COM-порт и `zstack` либо `ember`.
5. Запустите `start-coordinator.bat`.
6. Проверьте состояние через `status-coordinator.bat`.

Не запускайте две копии Zigbee2MQTT с одним USB-стиком. Порт может одновременно использовать только один процесс.

## Шаг 5. Дождитесь статуса ONLINE

Пакет подключается к `growerhub.ru:8883` по MQTTS. Кабинет проверяет статус автоматически. Когда координатор станет `ONLINE`, разрешите подключение на три минуты и переведите датчик в режим pairing рядом с USB-стиком.

Сначала дождитесь появления показаний и доступных свойств, затем перенесите датчик на рабочее место. Подробная проверка есть в материале [о подключении Zigbee-датчика температуры и влажности](/articles/podklyuchit-zigbee-datchik-temperatury-vlazhnosti/).

## Если координатор не выходит в сеть

| Симптом | Что проверить сначала |
|---|---|
| `No valid USB adapter found` | правильный COM-порт и значение `adapter`; официальные примеры находятся в [Adapter settings](https://www.zigbee2mqtt.io/guide/configuration/adapter-settings.html) |
| `Access denied` или порт занят | закройте вторую копию Zigbee2MQTT и программы прошивки/терминала |
| процесс запустился, GrowerHub показывает OFFLINE | наличие обоих YAML-файлов, системное время Windows и доступ к `growerhub.ru:8883` |
| после перезапуска пропали настройки | запускайте пакет из постоянной папки и не удаляйте каталог `data` |
| датчик не находится | pairing рядом с координатором, полный factory reset устройства, питание и логи Zigbee2MQTT |

Локальный интерфейс пакета доступен только на этом компьютере по `http://127.0.0.1:8080`. Открывать его в интернет не нужно.

## Проверка после перезапуска Windows

Перед обновлением сохраните резервную копию каталога `data`: в нём находятся конфигурация и состояние Zigbee-сети. Не смешивайте его с каталогом другой установки.

1. Остановите пакет через `stop-coordinator.bat` и запустите снова через `start-coordinator.bat`.
2. Проверьте процесс командой `status-coordinator.bat`, затем свежие показания в GrowerHub.
3. Перезагрузите Windows и повторите проверку. Наличие процесса ещё не означает, что координатор ONLINE.
4. Если используете Планировщик заданий, укажите полные пути и рабочую папку пакета. Проверьте запуск после входа или перезагрузки именно в выбранном режиме. Пакет сам не доказывает наличие автозапуска.

По состоянию на обновление статьи официальная [инструкция Zigbee2MQTT для Windows](https://www.zigbee2mqtt.io/guide/installation/05_windows.html) использует Node.js 22 LTS, Corepack и pnpm. Проверьте `node --version` и `corepack --version` до запуска пакета. После установки Node откройте новое окно терминала. Если Windows блокирует PowerShell-обёртку команды, используйте соответствующую `.cmd`-команду; не отключайте глобальные политики безопасности ради установки.

## Если Zigbee2MQTT уже работает

Не создавайте вторую Zigbee-сеть и не переносите все устройства ради GrowerHub. В мастере выберите вариант «Уже работает Zigbee2MQTT»: направленный connector сохраняет локальный MQTT и передаёт только нужные состояния и команды. Схема разобрана в статье [GrowerHub и Home Assistant через MQTT](/articles/growerhub-i-home-assistant-cherez-mqtt/).

## Готово, если

- Windows видит координатор на стабильном COM-порту;
- выбран правильный тип `zstack` или `ember`;
- `status-coordinator.bat` показывает запущенный процесс;
- GrowerHub показывает координатор `ONLINE`;
- первое устройство появилось с моделью, свойствами и свежими показаниями;
- после перезапуска компьютера каталог `data` остаётся на месте.

После этого создайте зону только по названию и назначьте ей устройство. Растения и автоматизации можно добавить позже.
